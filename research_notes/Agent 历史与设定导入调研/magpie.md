## 1. 支持哪些源，实际读取、写入什么，是否可以继续对话？

### Takeaway

Magpie 的“读取历史”“原 Agent 续聊”“跨 Agent 转换”“配置导入”是四种不同能力。实际跨格式转换仅 **Claude Code ↔ Codex**，另有 **Pi → oh-my-pi** 原生 fork；没有已实现的 Cursor/DSH/Claude/Codex → OpenCode 历史导入器，不能把 Magpie 的多源历史列表直接当作 Yuri onboarding 迁移能力。[carry_convert.go:78-79](../../../magpie/internal/sessions/carry_convert.go#L78-L79)、[carry.go:43-58](../../../magpie/internal/sessions/carry.go#L43-L58)。

### Inferences

- **推断**：Claude ↔ Codex 是“创建目标原生历史后用原 Agent resume”，比仅显示历史更接近真正续聊；但这不证明可在 Yuri/OpenCode 内续聊。必须另做 OpenCode 目标适配与运行验证，不能只接 Magpie API。[carry_convert.go:128-179](../../../magpie/internal/sessions/carry_convert.go#L128-L179)。
- **推断/风险**：Codex 文本过滤用 `strings.HasPrefix(t, "<")` 判断内部上下文，合法的用户 XML/HTML 开头文字也可能被跳过；不宜直接照搬到无损导入。[carry_convert.go:542-547](../../../magpie/internal/sessions/carry_convert.go#L542-L547)。

### Gaps

- 本次只读源码，未启动 Claude/Codex/OpenCode；仓库转换测试验证源不变、生成记录、Magpie 再读取、resume 命令与图片/压缩上下文，但所读测试没有运行真实 CLI 继续发一轮。因此“可续聊”是实现意图与格式测试证据，不是本机端到端实测结果。[carry_convert_test.go:81-160](../../../magpie/internal/sessions/carry_convert_test.go#L81-L160)、[carry_convert_test.go:163-250](../../../magpie/internal/sessions/carry_convert_test.go#L163-L250)、[carry_convert_test.go:284-325](../../../magpie/internal/sessions/carry_convert_test.go#L284-L325)。

## 2. 项目设定如何处理，去重、合并、重复导入与失败语义是什么？

### Takeaway

历史转换不自动迁移项目规则、MCP、skills、权限、模型设定或 memory；Magpie 用另外的 Library 子系统集中管理指令/MCP/skills，再按 Agent 格式分发。它有局部去重与保留用户字段机制，但没有通用“把多份异构聊天合进已有 OpenCode 会话”的功能；某些设定导入会**移动原文件内容**，并非只读复制。[carry_convert.go:9-20](../../../magpie/internal/sessions/carry_convert.go#L9-L20)、[library.go:1-5](../../../magpie/internal/library/library.go#L1-L5)、[instructions.go:470-524](../../../magpie/internal/library/instructions.go#L470-L524)。

### Cited Findings

#### 对话：不是全局幂等，也不合并已有目标会话

- `CarryOver` 不接收“目标已有会话 ID”，只创建新 ID。重复点击去重仅是**进程内 map**，key 为 `源path + 目标agent + size + mtime`，目标文件还在才复用。代码注释称“相同 bytes”，实际没有 hash/持久账本；源修改即创建另一新会话，重启 map 丢失，也会再次创建新会话。[carry_convert.go:114-179](../../../magpie/internal/sessions/carry_convert.go#L114-L179)、[carry_convert.go:696-697](../../../magpie/internal/sessions/carry_convert.go#L696-L697)、[carry_convert.go:833-841](../../../magpie/internal/sessions/carry_convert.go#L833-L841)。
- 失败时：不支持的源/目标、未授权、读文件失败、没有用户消息均返回 error；生成文件经同目录临时文件 → Flush → fsync → Close → Rename，目标已存在先拒绝，失败删除临时文件。没有批量会话迁移账本或整批事务；读取器遇坏 JSON 行是跳过而非汇总损失。API 的“打开终端”发生在文件创建后，终端打开失败会报错但不会删除已生成的历史。[carry_convert.go:128-179](../../../magpie/internal/sessions/carry_convert.go#L128-L179)、[carry_convert.go:292-305](../../../magpie/internal/sessions/carry_convert.go#L292-L305)、[carry_convert.go:425-444](../../../magpie/internal/sessions/carry_convert.go#L425-L444)、[carry_convert.go:596-627](../../../magpie/internal/sessions/carry_convert.go#L596-L627)、[sessions.go:490-501](../../../magpie/internal/gui/sessions.go#L490-L501)。
- 列表层的去重不是迁移合并：Claude 根据相同消息 UUID/compaction 关系把副本隐藏、分叉挂在原会话下；Cursor 同 ID 优先 CLI，DSH 同 session 只读最新文件代；这些不建立跨工具导入身份，也不会把历史写进现有目标会话。[cc_copies.go:13-51](../../../magpie/internal/sessions/cc_copies.go#L13-L51)、[cursor_editor.go:89-145](../../../magpie/internal/sessions/cursor_editor.go#L89-L145)、[dsh.go:89-103](../../../magpie/internal/sessions/dsh.go#L89-L103)。
- Claude 的 **Relocate project** 是另一能力：整目录搬迁，包含 subagents/tool results/project memory，改顶层 cwd 与 index 中路径，消息和 memory 正文中的旧路径不改；目标 project store 必须不存在，**明确不支持 merge/挑单会话/跨 WSL distro**。保留 original/manifest/staging，发布失败尝试还原源。该能力不能当“跨 Agent 项目设定导入”。[session-relocation.md:14-19](../../../magpie/docs/session-relocation.md#L14-L19)、[session-relocation.md:33-59](../../../magpie/docs/session-relocation.md#L33-L59)、[relocate_claude.go:240](../../../magpie/internal/sessions/relocate_claude.go#L240)。

#### 设定：Library 是另一个有写入副作用的工作流

- **存储目标**：`<magpie settings>/library.json` 记录 Instructions/MCP/Skills/Projects/Hooks/Subagents 和 Applied；文本与 skills 放 `<settings>/library/`。Applied 记录本工具写入的内容，便于只撤回自己的部分。[library.go:22-37](../../../magpie/internal/library/library.go#L22-L37)、[library.go:109-130](../../../magpie/internal/library/library.go#L109-L130)、[library.go:157-160](../../../magpie/internal/library/library.go#L157-L160)。
- **源设定格式**：Claude 的 `CLAUDE.md`、`.claude.json` MCP、`skills/`；Codex 的 `AGENTS.md`（另识别 `AGENTS.override.md`）、`config.toml` MCP、`skills/`；Cursor 有 `~/.cursor/mcp.json` 和 `skills/`，**该 target 没有 Instructions 字段，即不是 Cursor rules 导入器**；DSH 的 `AGENTS.md`、`skills/` 与 profiles 中 cordis patch MCP；OpenCode 的 config 目录 `AGENTS.md`、`skills/` 和 opencode 配置文件 MCP。[targets.go:153-164](../../../magpie/internal/library/targets.go#L153-L164)、[targets.go:181-191](../../../magpie/internal/library/targets.go#L181-L191)、[targets.go:218-226](../../../magpie/internal/library/targets.go#L218-L226)、[targets.go:254-257](../../../magpie/internal/library/targets.go#L254-L257)。
- **指令导入/合并**：`ImportInstructions` 读取源指令的用户自有部分，若 shared text 不包含整段 mine 则以空行追加；先更新 library 文本，再备份源文件，然后移除源文件自有部分（没有 marker block 时可能删除源指令文件），勾选该 Agent 让它以后读取共享指令。是**整段 substring 防重复 + append**，没有语义冲突处理/三方 merge。Alma owner profile 明确禁止这样导入。[instructions.go:470-524](../../../magpie/internal/library/instructions.go#L470-L524)。
- **MCP 合并/冲突**：按名字发现，配置相同则聚合 Agents，不同则进 `Others`；library 已有同名不再作为 found 提供。ImportServer 收入发现的 canonical entry 并标记拥有它的 Agent，后续同步采用 Agent 自身格式。DSH MCP 是 `@deepseek-ai/dsh-mcp-client` patch insert 行，不是标准独立 JSON 文件。[mcp.go:1624-1633](../../../magpie/internal/library/mcp.go#L1624-L1633)、[mcp.go:1674-1712](../../../magpie/internal/library/mcp.go#L1674-L1712)、[sync.go:931-951](../../../magpie/internal/library/sync.go#L931-L951)、[dsh.go:3-18](../../../magpie/internal/library/dsh.go#L3-L18)。
- **skills 去重/冲突/重复导入**：同真实目录聚合，另一目录但同树内容是 Copies，同名不同内容是 Others；导入已在 library 的同名项会拒绝。导入普通目录会移动进 library，原 Agent 改拿链接/副本；外链或共享 `~/.agents/skills` 保持源位置、library 建链接。同名异内容不做文本合并。批量 ImportSkills 的单项错误列入 `Unimported`，其他仍可成功；全部失败才返回整体 error。[skills.go:2124-2144](../../../magpie/internal/library/skills.go#L2124-L2144)、[skills.go:2147-2212](../../../magpie/internal/library/skills.go#L2147-L2212)、[skills.go:2283-2383](../../../magpie/internal/library/skills.go#L2283-L2383)。
- **项目设定范围有限**：Project 是用户显式添加的本地目录，记录该目录要给哪些 Agent 的 library skills/MCP 及本工具放入/写入的项；AddProject 只登记，重复真实目录拒绝。这里没有导入 Cursor `.mdc`/`.cursorrules`、Claude 项目规则或把它们编译成 AGENTS.md 的实现入口。项目分发支持 `.claude/skills`、共享 `.agents/skills`，MCP 目标有 `.mcp.json`、`.codex/config.toml`、`.cursor/mcp.json`、`opencode.json` 等；DSH 的 patch layers 没有 project MCP 层。[projects.go:16-47](../../../magpie/internal/library/projects.go#L16-L47)、[projects.go:49-89](../../../magpie/internal/library/projects.go#L49-L89)、[projects.go:332-356](../../../magpie/internal/library/projects.go#L332-L356)、[project_mcp.go:20-59](../../../magpie/internal/library/project_mcp.go#L20-L59)。
- **失败不等于全回滚**：一般 change 是 load → 执行 mutation → save library → sync Agent → 再 save；写一个 Agent 失败记录 `Problems`，不阻塞其他 Agent；变更前备份保留最近 30 次。指令导入也会先写 shared text 再做源文件处理，不是跨多个文件的原子事务；所以不能承诺“点击失败就完全没变”。[library.go:301-318](../../../magpie/internal/library/library.go#L301-L318)、[sync.go:15-38](../../../magpie/internal/library/sync.go#L15-L38)、[sync.go:70-71](../../../magpie/internal/library/sync.go#L70-L71)、[instructions.go:497-519](../../../magpie/internal/library/instructions.go#L497-L519)、[backup.go:16-24](../../../magpie/internal/library/backup.go#L16-L24)、[library.md:44-50](../../../magpie/docs/subsystems/library.md#L44-L50)。
- **不要混淆 provider import 的“merge”**：Import from other apps 实际列 Alma、CC Switch、Claude Code、Codex、OpenCode 的供应商配置，状态 new/same/taken，支持 add/replace/key；读源不写源。其“相同地址不同 key 合为多 key provider”不是聊天合并，也不是项目规则合并。本次只读该实现，不读其指向的用户配置。[importapps.go:3-8](../../../magpie/internal/provider/importapps.go#L3-L8)、[importapps.go:42-89](../../../magpie/internal/provider/importapps.go#L42-L89)、[importapps.go:125-129](../../../magpie/internal/provider/importapps.go#L125-L129)。

### Inferences

- Yuri 若要“可合并”，宜明确区分：①项目条目聚合；②同一来源重复导入幂等；③规则/MCP/skills 冲突合并；④聊天消息合并。Magpie 只提供部分②（进程内）与③（局部 canonical/substring/同树判定），不是四者一体的迁移器。建议持久化 `source + originalID + sourceRevision/hash → importedID`，源更新时提供跳过/新分支而非静默重复；聊天默认各自保留，不按标题合并。[carry_convert.go:114-179](../../../magpie/internal/sessions/carry_convert.go#L114-L179)、[skills.go:2147-2212](../../../magpie/internal/library/skills.go#L2147-L2212)。
- onboarding 若承诺不影响旧 Agent，不宜直接调用 ImportInstructions/ImportSkill；应设计**复制式导入、预览、冲突策略和可恢复账本**。Magpie 的接管式 Library 行为与“复制旧配置到 Yuri”并不相同。[instructions.go:470-524](../../../magpie/internal/library/instructions.go#L470-L524)、[skills.go:2283-2383](../../../magpie/internal/library/skills.go#L2283-L2383)。

### Gaps

## 3. 是否可独立复用，依赖与许可证如何，给 Yuri 的方案建议是什么？

### Takeaway

可复用的主要价值是格式知识、解析/转换算法与测试，不是一个可直接安装的通用迁移 SDK。源码是 Go `internal/sessions` / `internal/library`，与 Magpie 设置、Agent 发现、provider、catalog、proc 等内部模块耦合；Yuri 的 TypeScript/Node 工作流若要复用，需要提取/移植或另设 CLI 边界，不能假设已有 npm 模块。[sessions.go:12-43](../../../magpie/internal/sessions/sessions.go#L12-L43)、[carry_convert.go:26-44](../../../magpie/internal/sessions/carry_convert.go#L26-L44)、[targets.go:10-20](../../../magpie/internal/library/targets.go#L10-L20)、[library.go:8-20](../../../magpie/internal/library/library.go#L8-L20)。

### Cited Findings

- **较清晰的可提取 seam**：`carryItem` 是中间表示，读取 Claude/Codex → pairCarry → 目标 writer；但结构、reader、writer 均未导出，公共接口为 `CarryOver(Session,to)`，依赖全局路径/installed 检测、读取权限和列举以探测 Agent 版本。它尚不是“传入 reader、得到中性历史”的独立库。[carry_convert.go:46-79](../../../magpie/internal/sessions/carry_convert.go#L46-L79)、[carry_convert.go:128-179](../../../magpie/internal/sessions/carry_convert.go#L128-L179)、[carry_convert.go:653-685](../../../magpie/internal/sessions/carry_convert.go#L653-L685)。
- **较广覆盖的只读 seam**：`Session` 统一 id/cwd/title/时间/model/tokens/resume/path，`TranscriptOf` 返回 Parts/Cut。但完整 transcript 有 400,000 字符截断，且 DSH 不在支持列表，直接用 GUI transcript 作全量迁移中间格式会漏数据。[sessions.go:117-152](../../../magpie/internal/sessions/sessions.go#L117-L152)、[transcript.go:16-38](../../../magpie/internal/sessions/transcript.go#L16-L38)、[transcript.go:48-72](../../../magpie/internal/sessions/transcript.go#L48-L72)。

### Inferences

- **推荐仅作为方案输入，不直接落地实现**：
  1. 独立三层契约：`SourceAdapter`（授权后探测、只读分页/流读取）、无损 `ImportedConversation`（原 ID/分支/工具/附件/原始引用与损失清单）、`OpenCodeTarget`（用其拥有的导入机制写入并证明续聊）；Magpie 的 carryItem 可以启发中间表示，但应扩展 provenance、分支与损失标记。[carry_convert.go:46-63](../../../magpie/internal/sessions/carry_convert.go#L46-L63)、[carry_convert.go:281-324](../../../magpie/internal/sessions/carry_convert.go#L281-L324)。
