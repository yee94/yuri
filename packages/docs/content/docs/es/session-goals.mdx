# Objetivos de sesión

Yuri muestra el estado nativo de Goal de OpenCode. OpenCode gestiona el objetivo, la revisión, las continuaciones y los límites; Yuri no ejecuta otro bucle.

## Iniciar

Escribe `/goal <objetivo>` en una sesión de proyecto, revísalo y envíalo. Elegir la sugerencia solo inserta el comando. `/goal` sin argumentos muestra el motivo del objetivo actual; no prepara uno nuevo.

Describe el resultado y los criterios de verificación en un máximo de 4000 caracteres. Los planes, las sesiones derivadas de respuestas y las [tareas programadas](/es/scheduled-tasks/) también usan el mismo comando nativo para ejecutar un objetivo.

## Estado y controles

La franja muestra el objetivo, el estado nativo y el número de continuaciones. Abre los detalles para leer el motivo de OpenCode. Los estados son activo, pausado y completado. El ajuste de Chat solo controla la visibilidad; la interfaz es compartida por web, escritorio, VS Code y móvil.

- `/goal pause` pausa las continuaciones automáticas, sin interrumpir el trabajo en curso.
- `/goal resume` reanuda un objetivo pausado.
- `/goal clear` elimina el objetivo, sin interrumpir el turno actual.
- Para interrumpir el trabajo actual, usa el botón de detener de la sesión.

Yuri no añade presupuesto de tokens, resumen del objetivo ni pausas automáticas ante preguntas. Comprueba la finalización con los archivos y resultados reales.

## Ejecución

Cerrar una pestaña no detiene el servicio OpenCode. Mantenlo disponible durante la ejecución. Los antiguos objetivos de Yuri no se importan ni reanudan automáticamente; crea un objetivo nativo para continuarlos. Para trabajo recurrente, usa tareas programadas.
