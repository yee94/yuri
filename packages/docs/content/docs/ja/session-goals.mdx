# セッションゴール

Yuri は OpenCode の標準 Goal 状態を表示します。目標、評価、継続、制限は OpenCode が管理し、Yuri 独自のループは動きません。

## 開始する

プロジェクトの入力欄に `/goal <目標>` を入力し、確認して送信します。候補から選ぶだけでは送信されません。引数なしの `/goal` は現在のゴールの理由を表示し、新しいゴールを準備しません。

目標は 4000 文字以内で、完成条件と確認方法を明記してください。プラン、回答からの新規セッション、[スケジュールタスク](/ja/scheduled-tasks/)のゴール実行も同じ標準コマンドを使います。

## 状態と操作

入力欄の上に目標、状態、継続回数を表示します。詳細には OpenCode の理由が表示されます。状態は実行中、一時停止、完了です。チャット設定は表示だけを制御し、Web、デスクトップ、VS Code、モバイルで共通です。

- `/goal pause` は自動継続を一時停止します。実行中の作業は中断しません。
- `/goal resume` は一時停止したゴールを再開します。
- `/goal clear` はゴールを削除します。現在のターンは中断しません。
- 実行中の作業を中断するには、セッションの停止ボタンを使います。

Yuri はトークン予算、目標の要約、質問による自動一時停止を追加しません。完了は実際のファイルと実行結果でも確認してください。

## 実行元

ブラウザのタブを閉じても OpenCode サービスは停止しません。実行中はサービスを利用可能にしてください。旧 Yuri ゴールは自動移行・再開されません。続行には標準ゴールを作成し、定期実行にはスケジュールタスクを使ってください。
