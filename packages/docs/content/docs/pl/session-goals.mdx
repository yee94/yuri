# Cele sesji

Yuri wyświetla natywny stan Goal z OpenCode. OpenCode zarządza celem, oceną, kontynuacją i limitami; Yuri nie uruchamia osobnej pętli.

## Rozpoczęcie

Wpisz `/goal <cel>` w sesji projektu, sprawdź tekst i wyślij. Wybranie podpowiedzi tylko wstawia polecenie. Samo `/goal` pokazuje powód bieżącego stanu celu i nie przygotowuje nowego celu.

Opisz wynik i kryteria weryfikacji w maksymalnie 4000 znakach. Plany, sesje tworzone z odpowiedzi oraz [zaplanowane zadania](/pl/scheduled-tasks/) również uruchamiają cel przez to samo natywne polecenie.

## Stan i sterowanie

Pasek pokazuje cel, natywny stan i liczbę kontynuacji. Szczegóły zawierają powód podany przez OpenCode. Stany to aktywny, wstrzymany i ukończony. Ustawienie czatu wpływa tylko na widoczność; interfejs jest wspólny dla przeglądarki, pulpitu, VS Code i urządzeń mobilnych.

- `/goal pause` wstrzymuje automatyczną kontynuację, nie przerywając trwającej pracy.
- `/goal resume` wznawia wstrzymany cel.
- `/goal clear` usuwa cel, nie przerywając bieżącej tury.
- Aby przerwać bieżącą pracę, użyj przycisku zatrzymania sesji.

Yuri nie dodaje budżetu tokenów, skracania celu ani automatycznej pauzy przy pytaniach. Potwierdź ukończenie na podstawie rzeczywistych plików i wyników.

## Wykonanie

Zamknięcie karty nie zatrzymuje usługi OpenCode. Musi ona pozostać dostępna podczas pracy. Stare cele Yuri nie są automatycznie importowane ani wznawiane; aby je kontynuować, utwórz natywny cel. Do pracy cyklicznej używaj zaplanowanych zadań.
