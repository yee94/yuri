# Цілі сесії

Yuri показує вбудований стан Goal від OpenCode. OpenCode керує ціллю, оцінюванням, продовженням і обмеженнями; окремого циклу Yuri більше немає.

## Початок

Введіть `/goal <ціль>` у сесії проєкту, перевірте текст і надішліть. Вибір підказки лише вставляє команду. `/goal` без аргументів показує причину поточного стану цілі, а не готує нову ціль.

Опишіть результат і критерії перевірки в межах 4000 символів. Плани, сесії зі відповідей і [заплановані завдання](/uk/scheduled-tasks/) також запускають ціль тією самою вбудованою командою.

## Стан і керування

Смужка показує ціль, вбудований стан і кількість продовжень. У деталях можна прочитати причину від OpenCode. Стани: активна, призупинена та завершена. Налаштування чату впливає лише на відображення; інтерфейс спільний для вебу, настільної програми, VS Code і мобільних пристроїв.

- `/goal pause` призупиняє автоматичне продовження, але не перериває поточну роботу.
- `/goal resume` відновлює призупинену ціль.
- `/goal clear` видаляє ціль, але не перериває поточний хід.
- Щоб перервати поточну роботу, скористайтеся кнопкою зупинки сесії.

Yuri не додає бюджету токенів, скорочення цілі чи автоматичної паузи під час запитань. Перевіряйте завершення за фактичними файлами й результатами.

## Виконання

Закриття вкладки не зупиняє службу OpenCode. Під час виконання вона має залишатися доступною. Старі цілі Yuri не імпортуються й не відновлюються автоматично; створіть вбудовану ціль, щоб продовжити роботу. Для повторюваних завдань використовуйте розклад.
