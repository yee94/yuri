# Objectifs de session

Yuri affiche l’état natif Goal d’OpenCode. OpenCode gère l’objectif, l’évaluation, les continuations et les limites ; Yuri n’exécute plus de boucle distincte.

## Démarrer

Saisissez `/goal <objectif>` dans une session de projet, vérifiez le texte puis envoyez-le. Sélectionner une suggestion insère seulement la commande. `/goal` sans argument affiche la raison de l’objectif actuel ; il ne prépare pas de nouvel objectif.

Décrivez le résultat et ses critères de vérification en 4000 caractères maximum. Les plans, les sessions issues de réponses et les [tâches planifiées](/fr/scheduled-tasks/) utilisent la même commande native pour exécuter un objectif.

## État et commandes

La bande affiche l’objectif, son état natif et le nombre de continuations. Ouvrez les détails pour lire la raison fournie par OpenCode. Les états sont actif, en pause et terminé. Le réglage Chat contrôle uniquement l’affichage ; l’interface est commune au web, au bureau, à VS Code et au mobile.

- `/goal pause` suspend les continuations automatiques sans interrompre le travail en cours.
- `/goal resume` reprend un objectif en pause.
- `/goal clear` supprime l’objectif sans interrompre le tour actuel.
- Pour interrompre le travail actuel, utilisez le bouton d’arrêt de la session.

Yuri n’ajoute ni budget de tokens, ni condensation de l’objectif, ni pause automatique lors des questions. Vérifiez la fin du travail à partir des fichiers et résultats réels.

## Exécution

Fermer un onglet n’arrête pas le service OpenCode. Gardez ce service disponible pendant l’exécution. Les anciens objectifs Yuri ne sont ni importés ni repris automatiquement ; créez un objectif natif pour les poursuivre. Utilisez les tâches planifiées pour le travail récurrent.
