# Objetivos de sessão

O Yuri exibe o estado nativo de Goal do OpenCode. O OpenCode gerencia o objetivo, a avaliação, as continuações e os limites; o Yuri não executa outro ciclo.

## Iniciar

Digite `/goal <objetivo>` em uma sessão de projeto, revise e envie. Escolher uma sugestão apenas insere o comando. `/goal` sem argumentos mostra o motivo do objetivo atual; não prepara um novo objetivo.

Descreva o resultado e os critérios de verificação em até 4000 caracteres. Planos, sessões criadas a partir de respostas e [tarefas agendadas](/pt-br/scheduled-tasks/) também executam objetivos pelo mesmo comando nativo.

## Estado e controles

A faixa mostra o objetivo, o estado nativo e o número de continuações. Abra os detalhes para ler o motivo fornecido pelo OpenCode. Os estados são ativo, pausado e concluído. A configuração de Chat controla apenas a exibição; a interface é compartilhada entre web, desktop, VS Code e dispositivos móveis.

- `/goal pause` pausa as continuações automáticas sem interromper o trabalho em andamento.
- `/goal resume` retoma um objetivo pausado.
- `/goal clear` remove o objetivo sem interromper o turno atual.
- Para interromper o trabalho atual, use o botão de parar da sessão.

O Yuri não acrescenta orçamento de tokens, resumo do objetivo nem pausa automática diante de perguntas. Confira a conclusão nos arquivos e resultados reais.

## Execução

Fechar uma aba não interrompe o serviço OpenCode. Mantenha esse serviço disponível durante a execução. Os objetivos antigos do Yuri não são importados nem retomados automaticamente; crie um objetivo nativo para continuá-los. Para trabalho recorrente, use tarefas agendadas.
