# 세션 목표

Yuri는 OpenCode의 기본 Goal 상태를 표시합니다. 목표, 평가, 자동 계속 및 제한은 OpenCode가 관리하며 Yuri의 별도 목표 루프는 없습니다.

## 시작하기

프로젝트 입력창에 `/goal <목표>`를 입력하고 확인한 뒤 전송하세요. 자동완성에서 선택하면 명령만 삽입됩니다. 인수 없는 `/goal`은 현재 목표의 이유를 표시하며 새 목표를 준비하지 않습니다.

목표는 4000자 이내로 결과와 검증 기준을 명확히 작성하세요. 계획, 답변에서 새 세션 만들기, [예약 작업](/ko/scheduled-tasks/)의 목표 실행도 같은 기본 명령을 사용합니다.

## 상태와 제어

입력창 위에는 목표, 기본 상태, 계속 횟수가 표시됩니다. 상세 화면에서 OpenCode가 제공한 이유를 확인할 수 있습니다. 상태는 진행 중, 일시 중지, 완료입니다. 채팅 설정은 표시만 제어하며 Web, 데스크톱, VS Code 및 모바일에서 공통으로 사용합니다.

- `/goal pause`는 자동 계속을 일시 중지하며 실행 중인 작업은 중단하지 않습니다.
- `/goal resume`은 일시 중지된 목표를 재개합니다.
- `/goal clear`는 목표를 지우며 현재 턴은 중단하지 않습니다.
- 현재 작업을 중단하려면 세션의 중지 버튼을 사용하세요.

Yuri는 토큰 예산, 목표 요약 또는 질문에 따른 자동 일시 중지를 추가하지 않습니다. 완료 여부는 실제 파일과 실행 결과로도 확인하세요.

## 실행 주체

브라우저 탭을 닫아도 OpenCode 서비스는 중지되지 않습니다. 작업 중에는 서비스를 사용할 수 있어야 합니다. 이전 Yuri 목표는 자동으로 가져오거나 재개하지 않습니다. 계속하려면 기본 목표를 만들고 반복 작업에는 예약 작업을 사용하세요.
